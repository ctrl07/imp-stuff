# Contributing Guide

This project welcomes non-programmer contributions.

Current contributors: Our Coach, Mamta and Poonam.

You can safely contribute by:
- Adding documentation
- Improving UI text
- Suggesting new inspector fields
- Updating feature manifests

## Seek for guidance before:
- Attempting to add automation.
- Access the DOM from the UI
- Before sharing logic between features directly

When in doubt, keep changes small and readable and reach out for help.
