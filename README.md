# Imp Stuff — Project Overview

Imp Stuff is a browser extension designed to inspect, audit, and assist with my daily workflows.

It focuses on:

- Read-only analysis
- Clear presentation of existing data
- Conservative browser permissions
- Side-panel based workflows

This project is intentionally built to be:

- Maintainable by a single person
- Safe for non-coder contributions
- Resistant to feature creep

If you understand how data flows from a webpage to the UI, you understand the entire system.
